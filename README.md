# LiveTranslate

Рабочая версия исходников — 1.5.0 в разработке; готовность к публикации определяется релизной проверкой. Последняя опубликованная версия — 1.4.2.

Локальный перевод разговора на Windows. Микрофон и системный звук захватываются раздельно через WASAPI. В режиме «Авто · Whisper» речь распознаёт многоязычная модель Whisper. Английская и немецкая речь переводится на русский, русская на английский. Немецкий переводится через английский. Программа автоматически выбирает подходящую модель и ускорение.

## Запуск из исходного кода

Откройте эту папку в Visual Studio Code и нажмите F5 с установленным расширением Python Debugger. Также можно выполнить в PowerShell:

```powershell
.\.venv\Scripts\python.exe app.py
```

На вкладке «Перевод» выберите режим: «Микрофон», «Звук компьютера» или «Микрофон + компьютер», направление и нажмите «Начать перевод». Конкретные микрофон и устройство воспроизведения выберите заранее во вкладке «Настройки»; для системного звука нужно устройство со словом Loopback, на которое звонок выводит голос собеседника. Направление одно на сеанс; в автоматическом режиме язык определяется по речи. Наушники помогут исключить повторный захват голоса собеседника микрофоном.

По умолчанию звук обрабатывается в памяти. Опция «Сохранять звук в WAV» сохраняет файлы в папке «Документы/LiveTranslate/Recordings». Записи сохраняются при удалении программы. Кнопка «Остановить» завершает последнюю фразу и закрывает файлы. Программа показывает субтитры. Для передачи перевода голосом в звонок потребуется озвучка и отдельный аудиовыход.

## Текстовый перевод

Вкладка «Переводчик» переводит введённый текст локально после короткой паузы. По умолчанию язык определяется автоматически: русский переводится на английский, английский и немецкий — на русский. Отдельно можно выбрать русский → немецкий. Для коротких или неоднозначных слов определение может ошибаться. Для немецкого требуются дополнительные модели; перевод с русского на немецкий выполняется через английский. Ключ API и интернет для перевода не нужны.

## История и заметки

Каждый запуск перевода создаёт отдельный сеанс. Готовые фразы сохраняются по мере распознавания, а при остановке сеанс отмечается как завершённый. В разделе «История» можно выбрать сеанс, выделить и скопировать оригинал или перевод, а также удалить сеанс. Незавершённые сеансы остаются доступны после неожиданного закрытия.

В разделе «Заметки» создавайте заметки и папки, переименовывайте папки и перемещайте между ними заметки. Щёлкните правой кнопкой по заметке, чтобы переименовать или удалить её, либо по пустому месту списка, чтобы создать заметку. Двойной щелчок позволяет переименовать заметку прямо в списке. В редакторе доступны команды ПКМ «Вырезать», «Копировать» и «Вставить». При щелчке по слову с ошибкой меню может показать предложения системной проверки орфографии Windows для русского и английского, если соответствующие языковые средства установлены. Текст сохраняется автоматически. Удаление папки переносит её заметки в «Без папки». Доступна сортировка по названию и времени изменения. В поле перевода текст также можно выделить мышью и скопировать с помощью Ctrl+C.

История и заметки находятся в «Документы/LiveTranslate/library.sqlite3», а WAV-записи — в «Документы/LiveTranslate/Recordings». Они сохраняются при обновлении и удалении программы. Если папка «Документы» синхронизируется с OneDrive, эти данные могут синхронизироваться согласно настройкам Windows.

При первом запуске новая версия копирует прежние базу и WAV-записи из `%LOCALAPPDATA%/LiveTranslate`; исходники остаются там как резервная копия. Если новая база уже существует, она не перезаписывается и две базы не объединяются автоматически. Перед обновлением закройте прежнюю версию и не используйте её параллельно с новой, чтобы записи не оказались в разных базах.

## Определение языка

При наличии совместимой видеокарты NVIDIA и библиотек CUDA приложение использует GPU. Если обнаружено не менее 8 ГиБ видеопамяти и не менее 5 ГиБ свободно, а модель Turbo установлена, автоматически выбирается Whisper large-v3-turbo. Иначе используется Whisper Small. Если CUDA или Turbo не запускается, программа пробует Small на GPU, затем Small на CPU. На других видеокартах используется CPU. Для сборки с поддержкой NVIDIA установите зависимости из `requirements-gpu.txt` в дополнение к основным.

В режиме «Авто · Whisper» у каждой фразы видна метка EN → RU, RU → EN или DE → RU. Другой распознанный язык отображается своим кодом с оригиналом текста. Для смены языка сделайте небольшую паузу между репликами. Короткие слова могут определяться неточно. Два ручных направления используют потоковое распознавание Vosk и показывают промежуточные слова.

В автоматическом режиме Silero VAD проверяет наличие речи до запуска Whisper. Короткая пауза внутри предложения сохраняется. При длинной непрерывной речи программа использует время слов и знаки препинания, переносит незавершённую часть в следующее окно и передаёт Whisper контекст предыдущей реплики того же языка и голоса. Предварительный перевод стабильного текста может появляться во время речи; окончательный — после завершения фразы или длительной паузы. В настройках доступен экспериментальный профиль «Тихий голос» для автоматического режима Whisper; его качество на шуме и шёпоте ещё требует проверки.

Захват звука и запись WAV работают независимо от распознавания. Если системное устройство перестало присылать звук во время паузы, запись сохраняет соответствующий интервал тишины.

## Различение голосов в системном звуке

Для звонка или видео включите «Различать голоса» в панели «Звук компьютера». После паузы программа помечает оригинал и перевод как «Голос 1», «Голос 2» и так далее. При каждом новом запуске перевода нумерация начинается заново. Для короткой или неоднозначной реплики возможна метка «Голос не определён». При смене говорящего без паузы несколько голосов могут попасть в одну реплику. Одновременная речь не разделяется на отдельные дорожки.

Модель Vosk сравнивает голосовые признаки на компьютере. Образцы для сравнения остаются в памяти до остановки сеанса. Флажок можно отключить перед запуском.

В автоматическом режиме используются локальные модели WeSpeaker ResNet34 и pyannote segmentation, если при установке выбран компонент различения голосов. Без этих моделей используется Vosk. Метки могут ошибаться, особенно при одновременной речи; модель не разделяет смешанный звук на отдельные дорожки.

## Восстановление из Git

Установите Python 3.12 x64. В новой копии проекта выполните:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe models.py
.\.venv\Scripts\python.exe app.py
```

## Установщик для Windows

Готовый `LiveTranslate-Setup.exe` по умолчанию устанавливает приложение в `C:\Program Files\LiveTranslate` с правами администратора, без Python и Visual Studio Code; необходимые модели подготавливаются в фоне после установки. Для подготовки моделей требуется интернет. Русский и английский включены в базовый набор; немецкий перевод и различение голосов можно выбрать отдельно. Чтобы добавить компоненты позднее, повторно запустите установщик и выберите их. Ускорение NVIDIA определяется автоматически; при необходимости его можно выбрать вручную. Новые версии, установленные в Program Files, можно устанавливать поверх предыдущих; удалять их заранее не нужно. Первый переход со старой установки для текущего пользователя создаёт отдельную установку: старая версия и её запись в списке программ остаются на месте. Личные данные копируются при запуске новой версии. При желании прежнюю программу можно удалить после проверки копии данных. Удаление новой версии доступно в разделе «Установленные приложения» Windows; личные данные в «Документах» сохраняются. Записи старых версий в `Documents/VoiceTranslator Recordings` остаются в прежней папке.

После установки программа подготовки автоматически загружает модели в фоне и показывает прогресс. До завершения загрузки перевод недоступен; при сбое или отмене повторно запустите установщик. Загрузчик определяет NVIDIA и загружает библиотеки ускорения, а при наличии не менее 8 ГиБ видеопамяти также Whisper Turbo (около 1,6 ГБ). Модель Small сохраняется как резервная. При ошибке загрузки дополнительных GPU-компонентов подготовка продолжается с базовой моделью. При повторной установке проверяются контрольные суммы и скачиваются только отсутствующие или повреждённые файлы.

При установке по умолчанию предлагается создать ярлык LiveTranslate на рабочем столе; этот пункт можно отключить.

Для сборки установщика установите Inno Setup 7 и зависимости проекта. Библиотеки NVIDIA загружаются программой подготовки отдельно; при наличии подходящей видеокарты ускорение выбирается автоматически. Выполните:

```powershell
.\installer\build.ps1 -InnoCompiler "C:\Program Files\Inno Setup 7\ISCC.exe" -OutputDirectory ".\dist-installer"
```

Скрипт собирает приложение в небольшой EXE; модели загружаются после установки с проверкой SHA-256. При выборе NVIDIA программа подготовки проверяет SHA-256 загружаемых компонентов. Наличие драйвера NVIDIA проверяется при запуске; при отсутствии поддержки используется процессор.

Для сборки Windows-приложения:

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller==6.22.3
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm VoiceTranslator.spec
Copy-Item -Recurse data dist\VoiceTranslator\
```

Переносите папку сборки целиком. Исполняемому файлу нужны соседние каталоги `_internal` и `data`.
